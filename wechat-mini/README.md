# 在微信开发者工具里查看豆屿

这个目录是一个 **微信小程序 WebView 壳**，不是把整站重写成 WXML/JS 的原生小程序。

它做的事很简单：打开小程序后，用 `<web-view>` 加载豆屿的 H5 竖屏版：

```text
http://127.0.0.1:8787/#/mini
```

所以页面、按钮、集市、3D 都和浏览器里的小程序版完全一样。

## 一、电脑上先启动豆屿

在项目根目录运行：

```powershell
npm start
```

或者双击根目录的 `启动.bat`。

确认浏览器能打开：

```text
http://127.0.0.1:8787/#/mini
```

## 二、导入微信开发者工具

1. 打开 **微信开发者工具**
2. 选择「导入项目」
3. 目录选择本仓库的 `wechat-mini/` 文件夹
4. AppID 可以先用「测试号 / 游客 AppID」，也可以填自己的小程序 AppID
5. 进入后打开右上角「详情」→「本地设置」
6. 勾选：
   - **不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**

模拟器里就会加载豆屿的竖屏页面。

## 三、如果看到「页面不存在 / 冰箱对对碰」

这不是豆屿的页面，而是微信小程序的「页面不存在」兜底页。最常见的原因：

1. **导入/上传的是仓库根目录，而不是 `wechat-mini/` 子目录**
   - 根目录没有 `app.json`，微信找不到 `pages/index/index`
   - 必须选 `E:\湖北\douyu\wechat-mini`
2. **AppID 用成了别的小程序**
   - 截图里显示「冰箱对对碰」，说明当前打开的是另一个小程序
   - **小程序的名字、头像、AppID 是绑定在微信公众平台账号上的，改代码改不了名字**
   - 在开发者工具左上角确认项目名和 AppID；要叫「豆屿」，必须去微信公众平台新建一个自己的小程序，拿到新的 AppID
   - 不要复用「冰箱对对碰」的 AppID；否则上传后手机看到的还是「冰箱对对碰」
3. **测试号只能本地模拟器预览**
   - `touristappid` 可以编译、可以在模拟器看
   - 但不能上传成手机体验版；手机预览需要真实的小程序 AppID
4. **上传后没有把开发版设为体验版，或扫了旧二维码**
   - 在微信公众平台把刚上传的版本设为体验版，再扫新的体验版二维码

先检查 `wechat-mini/app.json`，应该能看到：

```json
"pages": ["pages/index/index"],
"entryPagePath": "pages/index/index"
```

## 四、如果模拟器里是空白

先确认：

- 电脑上的 `http://127.0.0.1:8787/#/mini` 能打开
- 微信开发者工具和豆屿服务在同一台电脑上
- 本地设置里已经勾选「不校验合法域名」

如果还是空白，把 `app.js` 里的地址改成电脑局域网 IP：

```js
globalData: {
  serviceUrl: 'http://192.168.1.23:8787'
}
```

同时用局域网模式启动服务：

```powershell
$env:DOUYU_HOST='0.0.0.0'
npm start
```

手机和电脑连同一个 Wi-Fi，手机浏览器先访问 `http://192.168.1.23:8787/#/mini`，确认能打开。

## 五、真机注意

微信小程序的 `web-view` 在**真机/正式版**上默认要求：

- HTTPS 域名
- 在公众平台配置「业务域名」

所以：

- **开发者工具模拟器**：可以靠「不校验合法域名」直接看
- **真机预览**：最稳的是把豆屿部署到 HTTPS 域名，再把这个域名配成业务域名
- 只想看效果：直接手机浏览器打开 H5 地址也可以

## 六、想要真正的小程序包

现在这层只是 WebView 壳。如果要变成真正原生小程序，需要把 React 页面改写成：

- WXML / WXSS
- 小程序 JS
- 3D 部分接微信 WebGL（three-platformize 等）

这是另一套工程量，不是导入这个壳就能自动完成的。
